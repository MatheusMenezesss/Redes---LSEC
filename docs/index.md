# Network Infrastructure Research Documentation

Welcome to the Docs-as-Code portal for this monorepo.

## Purpose

This documentation site centralizes:

- Research architecture and conventions
- Infrastructure decisions and RFCs
- Reproducibility and experiment standards

## Start here

1. Read the repository `README.md` for onboarding.
2. Propose major changes using the RFC process.
3. Keep experiment-level notes close to code in `experiments/`.

## RFC workflow

- Copy `docs/rfcs/0000-rfc-template.md` to the next available RFC number.
- Open a PR with technical rationale and migration/research impact.
- Get peer review before implementation.
